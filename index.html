01 · About me

Quality is a habit, not a final step

I'm a QA Engineer based in India who enjoys finding the gap between how software is expected to work and how it actually behaves. Since October 2024 I have been working as a QA Engineer, testing web applications that handle sustainability reporting, request and approval workflows, budgeting and operational planning.

My work covers the full testing cycle: reviewing requirements, writing test cases, executing functional and regression testing, logging clear defects in Azure DevOps and confirming fixes. I also build Playwright automation in JavaScript so that repeated checks become faster and more consistent.

I'm now looking for my next opportunity as a QA Engineer or Software Test Automation Engineer, where I can keep growing my automation skills while protecting product quality.

My testing approach

  1. 1

    Understand

    Review requirements and user stories early, and raise questions before they become defects.

  2. 2

    Design

    Write test cases covering positive, negative, boundary and role-based scenarios.

  3. 3

    Execute & report

    Test methodically and log defects with clear steps, expected results and evidence.

  4. 4

    Validate & automate

    Retest fixes, run regression and automate repeatable checks with Playwright.
